# ADR-0002: moved to the deployment record

**Status:** Moved 2026-10-16, by ADR-0019 decision B.

This number held a record of how one running instance of nervus is given its network address,
and how its clients find it. That is about operating that instance, not about nervus, so it is
kept in the instance's deployment record (`deployment/0002-nervus-addressing.md`), which is not
published. The number is not reused. Anything citing ADR-0002 means that note.
